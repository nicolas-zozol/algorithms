Leet code typical algorithm choice
====

In general, think of HashMap first, as it's O(n)

Given:

* Array sorted
    * binary search
    * two pointers

* Generate **all**, find **all**
    * Brute force
    * Backtracking

* LinkedList
    * two pointers

* Top/least k items
    * Heap (aka PriorityQueue in Java)

* Strings
    * Trie
    * Map

* Sum
    * Find the complement, use HashMap
